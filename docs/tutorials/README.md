# Tutorials

Guided lessons that walk a newcomer through the project, learning by doing.

Each tutorial should:

- Be practical and hands-on (the reader produces something working).
- Assume **no prior knowledge** of the project.
- Focus on learning, not on exhaustive reference: link to `../reference/` for details.

# How-to Guides

Step-by-step recipes for achieving specific goals with the project. The reader is assumed to already understand the basics (see `../tutorials/` if not).

Each how-to should:

- Be goal-oriented: "How to ___".
- State prerequisites up front.
- Provide a clear sequence of steps that leads to the stated goal.

## Index

- [Add or edit a page](add-or-edit-a-page.md): the everyday content recipe, covering slugs, templates, frontmatter, locale sections, linking and drafts.
- [Remove a page](remove-a-page.md): delete or hide a page cleanly, including reference cleanup and redirects for old addresses.
- [Translate a page](translate-a-page.md): add a missing language section to an existing page and track the gaps.
- [Edit the menus and the footer](menus-and-footer.md): navigation, call-to-action button and footer columns in `config.json`, including dropdowns.
- [Hide a page from the sitemap, or redirect an old address](exclude-or-redirect-pages.md): `pages.excluded`, `pages.redirects`, and the draft/noindex frontmatter alternatives.
- [Publish news and author pages](news-and-authors.md): news articles, categories, link-outs, author records and the generated listings.
